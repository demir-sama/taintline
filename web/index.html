Retraction contamination, traced

Your agent cited a clean paper.
That paper cited a retracted one.

Taintline is a citation graph on HydraDB that answers one question for research agents: does this paper's evidence chain lead to retracted work? It starts knowing only the retraction list, reads references only when a question needs them, and gets sharper with every question it answers.

Snapshot: from OpenAlex (CC0). Precomputed demo of a real HydraDB run; live mode is in the repo.

        How it learns
        
  
          
    
        1. Seed. The graph starts with the public retraction list and nothing else.
          2. 
    
        2. Ingest the gap. A question reads the paper's references (one fetch) and asks HydraDB for a path to a retraction.
          3. 
    
        3. Expand where the graph points. No path yet? HydraDB ranks unread references by how many already-ingested papers cite them, and Taintline reads the top one. Up to 3 times.
          4. 
    
        4. Keep everything. Every reference list it reads stays in the graph, so the next question in that area starts closer to the answer. That is why the curve rises.

        // one traversal answers "is there a retraction within two citations?"
MATCH (q:Work {id: $q})-[:CITES]->(x:Work)-[:CITES]->(r:Work)
WHERE r.retracted = 1 RETURN x.id AS via, r.id AS rid

// where to read next: unread references, ranked by what the graph already knows
MATCH (q:Work {id: $q})-[:CITES]->(x:Work)<-[:CITES]-(p:Work)
WHERE x.fetched = 0
RETURN x.id AS id, sum(p.verdict) AS score, count(*) AS citers
        
  
        
  
        
    
        Why not a vector store?
        
    
        Contamination is a fact about citations, not about wording. A vector store finds papers that sound like retracted work, so it flags honest papers on the same topic and misses chains that go through a paper with different wording. Taintline only says "tainted" when it can show the citation path, so every flag is checkable.

          Who pays
          
  
          
    
          Buyer
          Research-integrity teams at publishers and journals, systematic-review groups, pharma medical-affairs teams, and makers of AI research agents (Elicit-style tools, literature-review copilots) who cannot afford to cite retracted evidence.
          
    
          Wedge
          An agent tool and API: check(doi) returns a verdict and the citation path in under 100 tokens. Drop it into an agent's toolset or a manuscript-submission check. Every customer query also enriches the shared graph.
          
    
          Pricing
          Free: 100 checks/month. Pro $49/month: 10k checks and webhook alerts when a paper you cite gets a newly retracted ancestor. Publisher plan from $1,500/month: bulk manuscript screening and audit export.
          
  
          
  
          Market signal: Retraction Watch's database lists more than 50,000 retractions, and Crossref has distributed it openly since 2023. Citation of retracted work after retraction is a documented, ongoing problem.
